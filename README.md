### 学术成果

**Phonon Density of States Prediction from the Pre-trained Phonon Transformer**

npj Computational Materials (Nature Portfolio) · IF: 11.9 · JCR Q1 · 中科院材料 1 区 TOP

> 提出 PPhT 模型，将径向基函数编码距离与球谐函数编码方向融合至 Transformer 注意力机制，在 24,000+ 数据、86 种元素的声子态密度预测任务上超越 SOTA，单样本推理耗时 < 30ms。
